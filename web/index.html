Four ways a mission goes wrong

The places that matter most are the ones we can't see into.

Unknown terrain

No map. No visibility. Nobody knows what is behind the door.

GPS denied

Underground, in forests and under rubble, drones lose their position.

Too risky

Soldiers should not be the first ones through.

One drone is not enough

Short endurance and a narrow view. Swarms add chaos when comms and coordination fail.

Five layers. Swap any one without touching the rest.

Each layer talks to the next through ROS 2 topics, so a better planner or a new sensor drops in without a rewrite.

Perception

LiDAR and depth, split into left, front and right sectors.

sensor → sectors

Mapping

2.5D occupancy grid with ghost clearing for moving obstacles.

sectors → grid

Planning

Dynamic A* replans at about 2 Hz. A B-spline smooths the route.

grid → path

Control

State machine running on PX4 Offboard mode.

path → setpoints

Coordination

Shared maps now. Multi-agent reinforcement learning is planned.

map ⇄ map

What it delivers

  • See the unseen. Map blind spots with no one at risk.
  • No GPS needed. Underground, forest, rubble.
  • Redundancy. The mission survives a lost drone.

How we build it

  • Modular. Upgrade any layer.
  • Reproducible. Open source, public code.
  • Fair evaluation. Fixed metrics and scenarios.
  • Research. Review paper submitted, 5 gaps found.
  • Ethical. Simulation only, with human oversight.
